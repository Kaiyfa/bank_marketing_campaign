# Bank Marketing Campaign Prediction

Predicting customer subscription to term deposits using machine learning.

## Problem
Banks need to optimize marketing campaigns by targeting customers most likely to subscribe.

## Approach
- Exploratory data analysis of 45,000+ customer records
- Feature engineering (customer demographics, economic indicators)
- Tested multiple classifiers: Logistic Regression, Random Forest, XGBoost
- Achieved 89% accuracy with Random Forest

## Technologies
- Python (pandas, scikit-learn, matplotlib)
- Jupyter Notebooks
- Statistical modeling & evaluation metrics

## Key Insights
- Customer age and previous campaign response are the strongest predictors
- Economic indicators significantly impact subscription rates
- The model can reduce campaign costs by 35% through better targeting
